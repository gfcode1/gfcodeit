# Soundscape

Ambient sound mixer — layer looping sounds and set per-sound and master volume.

Sound files are vendored from [remvze/moodist](https://github.com/remvze/moodist)
(`pnpm sounds:sync` re-downloads them into `apps/soundscape/sounds/`). Moodist's
code is MIT-licensed; its audio files are third-party, under the Pixabay Content
License and CC0.
